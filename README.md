# شاشة — Shasha

مشغّل IPTV عربي خفيف وسريع يعمل في المتصفح. واجهة سينمائية داكنة باتجاه RTL، وبحث فوري، ومفضلة،
وسجل مشاهدة، ودعم M3U وXtream Codes، وتشغيل HLS وMP4 دون حسابات أو إعلانات.

## المزايا

- إضافة قوائم التشغيل بأربع طرق: رابط M3U، ملف من الجهاز، لصق المحتوى، أو حساب Xtream Codes.
- تشغيل HLS عبر `hls.js` (يُحمَّل عند الحاجة فقط) وMP4 عبر مشغّل المتصفح.
- تصفية حسب المجموعة، بحث عربي متسامح مع التشكيل والأرقام، وقائمة قنوات افتراضية للأداء العالي.
- مفضلة وسجل مشاهدة وآخر قناة لكل قائمة، محفوظة محلياً في `localStorage`.
- أدوات مشغّل كاملة: تشغيل/إيقاف، كتم، مستوى الصوت، جودة HLS، صورة داخل صورة، وملء الشاشة.
- اختصارات لوحة المفاتيح: مسافة (تشغيل)، M (كتم)، F (ملء الشاشة)، N/P (التالية/السابقة).
- تصميم متجاوب لسطح المكتب والجوال، مع احترام `prefers-reduced-motion`.

## التشغيل السريع

```bash
pnpm install
pnpm dev          # http://localhost:3000
```

## إضافة قنوات Xtream Codes

1. افتح «إضافة قائمة تشغيل» ثم تبويب **Xtream**.
2. أدخل رابط الخادم (مثل `http://example.com:8080`) واسم المستخدم وكلمة المرور.
3. يتحقق الخادم من الحساب عبر `player_api.php`، ثم يجلب التصنيفات والقنوات المباشرة.
4. تُبنى روابط البث بصيغة HLS: `/live/<user>/<pass>/<stream_id>.m3u8`.

ملاحظات مهمة:

- يدعم شاشة البث المباشر بصيغة **HLS (m3u8)** فقط. القنوات التي تقدم MPEG-TS خاماً أو DASH
  قد لا تعمل في المتصفح.
- تُرسل بيانات الدخول إلى خادمك عبر وسيط شاشة لجلب القائمة، ثم تُحفظ القنوات محلياً على جهازك.
  لا تُرسل البيانات إلى أي خدمة أخرى.
- يجب أن يسمح خادم Xtream بالطلبات من المتصفح (CORS) ليعمل تشغيل الفيديو مباشرة.
- الحد الأقصى 10,000 قناة للقائمة الواحدة، وتُعرض رسالة عند الاقتطاع.
- القوائم الكبيرة قد تستهلك مساحة `localStorage`؛ تظهر تحذيرات عند تجاوز الحد.

## وسيط القوائم وM3U

- `GET /api/playlist?url=...` يجلب نص M3U عبر الخادم لتجاوز CORS.
- يمنع العناوين المحلية والشبكات الخاصة، ويعيد فحص كل إعادة توجيه.
- يحدّ حجم الاستجابة بـ 8 ميغابايت والمهلة بـ 15 ثانية، مع حد للطلبات لكل عنوان IP.
- إذا فشل الوسيط، يحاول التطبيق الجلب المباشر من المتصفح، ثم يقترح تنزيل الملف وإضافته من تبويب «ملف».

## النشر

### Cloudflare Workers (الصفحات + واجهات API)

```bash
pnpm dlx wrangler login     # مرة واحدة
pnpm cf:build
pnpm cf:deploy
```

يعطيك رابطاً على `*.workers.dev` مجاناً. راجع `wrangler.jsonc` لإضافة D1/KV/R2 عند الحاجة.

> **مهم:** يحتاج شاشة إلى خادم يشغّل Route Handlers من أجل `/api/playlist` و`/api/xtream`،
> لذلك لا يدعم التصدير الثابت (GitHub Pages). استخدم Cloudflare Workers أو أي خادم Node يدعم Next.js.

## حدود معروفة

- لا يدعم DRM ولا بث DASH (`.mpd`).
- يعتمد تشغيل القنوات على سماح مزوّد البث بـ CORS، وقد تتعطل روابط القنوات العامة لاحقاً.
- بيانات المكتبة محلية لهذا المتصفح؛ لا توجد مزامنة بين الأجهزة.
- القائمة التجريبية تستخدم بثوثاً عامة قابلة للتغيير، وقد تتوقف بعض القنوات.

## ملاحظات تقنية

- Next.js 16 (App Router + Turbopack) وTailwind CSS 4، مع `lang="ar"` و`dir="rtl"`.
- `typedRoutes` مفعّل: استخدم مسارات معروفة وقت البناء.
- لا ترفع `.env.local` أو أي أسرار إلى Git.
